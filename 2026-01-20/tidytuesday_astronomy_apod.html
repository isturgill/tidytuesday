1 Introduction

From the TidyTuesday README for 2026-01-20:

This week we’re exploring the Astronomy Picture of the Day (APOD) archive. APOD is a popular NASA website featuring daily astronomy related images with a scientific explanation.
Each day a different image or photograph of our universe is featured, along with a brief explanation. This APOD archive contains image information from the 2007 - 2025, pulled together into the astropic R package.

  • What types of objects are most common in the archive?
  • Are any images posted more than once?

Thank you to Erin Grand for curating this week’s dataset.

The author recommends removing the service_version column, which just contains the value v1 for every row. Let’s also filter out rows that don’t have data we need to answer the two questions presented in the Section 1, specifically: media_type and title.

# Remove unneeded service_version column
# Then, filter to remove rows with missing data needed for our analyses
hist_apod <- hist_apod |>
  select(-service_version) |>
  filter(!is.na(media_type) & !is.na(title))

2.3 Assumptions

Now, we should be good to go, noting a couple of assumptions:

  1. The media type is accurately recorded and “other” is genuinely a non-image, non-video type, rather than a collection or some other overlap with those categories.
  2. If an image was posted more than once, it would have the exact same title each time it was posted.

3.1 Most common object types

Let’s first take a look at the most common object types (media_type):

data_title <- "Most frequent media types in the Astronomy Picture of the Day Dataset"

# Show the tibble first
hist_apod |>
  summarize(num_media = n(), .by = media_type) |>
  arrange(desc(num_media)) |>
  head()
media_type num_media
image 6712
video 399
other 34 
# Now plot the data
hist_apod |>
  summarize(num_media = n(), .by = media_type) |>
  arrange(desc(num_media)) |>
  ggplot(aes(x = reorder(media_type, -num_media), 
             y = num_media,
             fill = media_type)) +
  geom_col() +
  scale_fill_npg() +
  guides(fill = "none") +
  labs(title = data_title,
       subtitle = tidy_tuesday,
       x = NULL,
       y = "Number of media objects in dataset") +
  theme_bw()

Here we can see that the most common media type, vastly outnumbering the other media types, is “image,” which makes sense – this is the Astronomy Picture of the Day dataset, after all.

  labs(title = data_title,
       subtitle = tidy_tuesday,
       x = NULL,
       y = "Number of times posted") +
  theme(axis.text.x = element_text(angle = 45, vjust = 1, hjust = 1)) +
  theme_bw()

The winner of most-popular (most re-posted) image is “The Horsehead Nebula,” at 11 posts.
